# Studio de Conteúdo — template (motor)

Motor reutilizável de um site-estúdio de conteúdo. Customize para o seu nicho:

1. `config.js` — marca (nome, @, iniciais, caption) e paleta da arte.
2. `style.css` (`:root`) — paleta do site.
3. `index.html` — rótulos das abas (Biblioteca/Frases).
4. `app.js` (`CATS`) — nomes das categorias (opcional).
5. `posts.js` / `radar.js` / `produtos.js` / `motivacional.js` — conteúdo.
6. `foto.js` (opcional) — `window.SG_FOTO` com a foto em base64.

Teste abrindo `index.html`. Publique no Netlify (drag-and-drop ou via GitHub).
Veja o passo a passo completo no SKILL.md.
